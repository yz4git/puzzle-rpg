# Puzzle RPG

iPhoneの縦画面を主対象にしたパズルRPGです。

## Foundation

`yz4git/sky-dancer` の実績あるWeb/iPhoneゲーム基盤を初期テンプレートとして複製し、`yz4git/puzzle-rpg` 用に分離しています。

- React / TypeScript / Vite / Next-compatible build foundation
- PWA / service worker foundation
- iPhone Safari向けの既存運用・検証基盤

## Project rules

- Target repository: `yz4git/puzzle-rpg` only
- Primary device: iPhone Safari
- Primary orientation: portrait
- Do not reuse Sky Dancer's ChatGPT Sites project/hosting identity
- Build the puzzle-RPG gameplay as a new game while reusing only suitable platform/runtime foundations
